# v0.2.4 — Gate 2 Edit Flow + Injury Badge Polish

- QUESTIONABLE status on player-selection screens is now rendered as the same yellow warning pill used on review/home lineup cards.
- Editing a completed lineup is now a one-position operation: after changing a healthy starter, the app returns directly to **Review My Five** instead of advancing to the next position.
- If the edited starter is QUESTIONABLE, the app first requires an emergency backup, then returns directly to review.
- Back navigation during a one-position edit returns to Review My Five rather than stepping backward through the original build sequence.
- Injury-backup repairs launched from the lineup home return to the lineup home when complete.
- Initial QB → RB → WR → TE → K building behavior is unchanged.
