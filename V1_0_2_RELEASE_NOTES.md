# v1.0.2 — Sunday Confidence + Weekly Recap

This release is intentionally narrow. It starts from the v1.0.1 public-launch baseline and adds only the two pre-Week-1 polish items selected for launch.

## Sunday Status Card
- Adds a one-glance pre-lock card on the real weekly Sunday screen.
- Clearly shows whether the lineup is ready, incomplete, needs an emergency backup, or contains an OUT starter.
- Keeps Questionable starters visible even after a valid emergency backup has been saved.
- Shows a compact time-to-lock line.
- Shows NFL-data freshness and warns when the data is older than expected inside the final two hours before lock.

## Monday Weekly Recap
- Replaces the live Sunday-storyline block with a richer recap once the week is FINAL.
- Highlights weekly champion/co-champions.
- Adds Most Popular Pick, Boldest Solo Pick, Closest Finish, Same Brain, and Biggest Mover.
- Week 1 uses a Season Race starter card because there is no prior ranking to move from.
- Adds a Share Results expander with a clean group-chat recap and a copy button.

## Scope Guard
No scoring, lock, emergency-backup activation, season-points, authentication, commissioner, NFL-provider, Supabase-schema, or GitHub Actions behavior was changed.

No SQL migration, new secret, Supabase setting change, or workflow change is required.
