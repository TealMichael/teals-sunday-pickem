v1.0.7 — Sunday Clock Broadcast + Commissioner Cleanup

Adds a separate Sunday-only AWTRIX broadcast layer with optional week-specific Welcome, Party, and Custom messages; full live weekly standings; all live NFL game scores; 25-player-pool-only Player Updates; Week 2+ season standings; Pick'em Pulse; and a safe Test Clock sequence. Commissioner mode is cleaned to Week / Players / Corrections / Clock / Diagnostics, with accumulated launch/recovery/test tools consolidated under Diagnostics. Pre-lock clock output preserves pick secrecy. The physical clock uses a publishable Supabase key plus a scoped/revocable token whose plaintext is never stored server-side. The proven live NFL scoring engine and GitHub workflows are unchanged.
